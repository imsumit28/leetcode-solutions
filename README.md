# github-solutions

My LeetCode solutions, auto-synced to this repository using the [LeetSync](https://github.com/rowan-mitchell/LeetSync) browser extension.

## How it works

Whenever I submit an **accepted** solution on LeetCode, the LeetSync extension automatically pushes it to this repo — no manual copy-pasting required.

## Structure

Each problem gets its own folder, containing:
- The solution file (in the language submitted)
- A `README.md` with the problem statement / notes (if enabled)

```
github-solutions/
├── 1-two-sum/
│   └── solution.py
├── 2-add-two-numbers/
│   └── solution.js
└── ...
```

## Note

Solutions here are synced automatically and may not always be the most optimized — just what passed on submission. Feel free to explore, but treat this as a personal practice log rather than a curated solutions repo.
